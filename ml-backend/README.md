# Road SOS ML Backend

FastAPI service for the Road SOS RandomForest accident motion-pattern classifier.

The Expo app does **not** load `accident_model_real.pkl` directly. It collects accelerometer/gyroscope samples, extracts the feature vector, sends it to `/predict`, and combines the model result with GPS/context rules before starting the SOS countdown.

## Render Deployment

The root project has `render.yaml`, so Render can deploy this backend directly from GitHub.

Render settings:

- Root Directory: `ml-backend`
- Build Command: `pip install -r requirements.txt`
- Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
- Health Check Path: `/health`
- Runtime: `python-3.11.9`

After deployment, set the mobile app env var:

```env
EXPO_PUBLIC_ML_API_URL=https://your-road-sos-ml-backend.onrender.com
```

For the final hackathon demo, use the deployed Render URL, not `127.0.0.1`, `localhost`, or a laptop IP.

## Optional Local Setup

```bash
cd ml-backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Then add this to the Expo app `.env` only for local debugging:

```env
EXPO_PUBLIC_ML_API_URL=http://YOUR_COMPUTER_LAN_IP:8000
```

For testing on a real phone, do not use `localhost`. Use your computer LAN IP, for example:

```env
EXPO_PUBLIC_ML_API_URL=http://192.168.1.10:8000
```

## Endpoints

`GET /health`

```json
{
  "status": "ok",
  "modelLoaded": true
}
```

`POST /predict`

Accepts the statistical feature payload generated by the mobile app and returns:

```json
{
  "prediction": "accident",
  "probability": 0.87,
  "riskLevel": "HIGH",
  "modelUsed": true
}
```

## Safety Note

MotionSense is a real iPhone accelerometer/gyroscope dataset, but it is mainly a human activity recognition dataset, not a real-world road crash dataset.

The ML model improves sensor-pattern classification for the MVP, but real-world deployment would require training and validation on actual two-wheeler crash and near-crash data.

Road SOS remains a hackathon MVP. Emergency dispatch is simulated.
